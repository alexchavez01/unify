
# Usability Study Debrief for *Unify* Platform

**Summary of Findings**

- **Usability Issues Identified:**
  1. **Overlooked Clear Labeling for Filters**: Some users were unsure of what each filter option in the matching system represented, making it hard for them to effectively use the filtering features.
  2. **Lack of Visual Cues for Dorm Availability**: Users had difficulty understanding whether dorms were available or not. This made it harder to evaluate listings and mark favorites.

- **Key Insights:**
  - **Navigation Flow**: The platform's overall layout was appreciated, but small tweaks to enhance flow (e.g., clearer navigation between sections) could improve the experience.
  - **Personalization**: The matching feature was well-liked, but additional guidance or a more straightforward process would make it easier to find relevant matches.

---

**Ranked Issues**

1. **Overlooked Clear Labeling for Filters**: Make the filter options clearer by adding labels or tooltips to explain what each option does.
2. **Lack of Visual Cues for Dorm Availability**: Add visual indicators like color-coded status (available, unavailable) to make it easier for users to understand dorm availability.

---

**Resolution Plan**

- **Overlooked Clear Labeling for Filters**: Update the filter UI to include clear labels or tooltips for each filter option to guide users better.
- **Lack of Visual Cues for Dorm Availability**: Introduce visual cues such as color-coded status indicators to clearly mark dorm availability.
