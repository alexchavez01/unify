## Project Description

Our project aims to build a platform that enhances student connectivity within colleges and provides a crowdsourced ecosystem for academic and extracurricular opportunities.  
The platform will facilitate peer connections, enable resource sharing, and streamline access to relevant information through intelligent features.

---

## Purpose and Motivation

- Foster meaningful academic and social connections among students.
- Simplify resource sharing, peer tutoring, and information exchange.
- Create an intelligent, centralized hub for academic and extracurricular support.
- Empower students through a crowdsourced and community-driven platform.

## Setup, Build, and Run Instructions

### Prerequisites

- **Node.js** version 18 or higher
- **npm** or **yarn** installed

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Wooster-CS320-SP25/prestige-view.git
   cd prestige-view

2. **Install Core Dependcies**

# Install core dependencies

Make sure you are in the right directory:   `../prestige-view/prestige-view-app`

Then donwload these in case if you dont have them:

`npm install` (Only install this if you dont have npm installed)

`npm install react react-dom next`
`npm install lucide-react`
`npm install class-variance-authority`
`npm install clsx`
`npm install tailwind-merge`

3. **Run Project**

Again make sure you are in the right directory else it will not run: `../prestige-view/prestige-view-app`

In terminal:
`npm run dev`

Then open your browser and go to:
`http://localhost:3000`
